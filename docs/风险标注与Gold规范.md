# 风险标注与 Gold 规范

> **状态：正式版**（与当前风险评测 Gold 一致，84 份测试集 / 152 条风险标注）。
> 本文档规定本项目「风险识别」评测 Gold 的标注原则、风险类别定义、边界判定规则及一致性控制方法。

---

## 一、文档目的与适用范围

本文档是「风险识别」评测的 **Gold 标注规范**。评测脚本 `backend/evaluate/evaluate_evidence.py` 将引擎输出与 Gold 逐条比对，计算精准率/召回率/F1。标注者在建立 Gold 时，**只依据本规范与合同正文判断，不参考规则引擎或 LLM 的任何输出**，以保证 Gold 客观中立、独立于被评测的系统。

---

## 二、核心标注原则

**一条条款标为风险，当且仅当：它有明确法条依据，或对一方造成实质不利。模棱两可的不标。**

判定顺序（逐条判断）：

1. 这条对某方（多为弱势方/委托方）会造成实际损失或维权困难吗？——是 → 标
2. 能找到法条依据吗（民法典 585/590/496/497/859 等、劳动法、个保法、招标投标法）？——能 → 标
3. 只是"写法不规范/措辞模糊但没有实质损害后果"？——是 → **不标**
4. 双方权利义务对等、行业惯例如此、无单方优势？——**不标**

**「实质不利」操作化定义**：让一方承担超出正常商业对价的成本、风险或责任，具体包括：

- 责任无上限/无边界（全部损失、一切责任）
- 权利单方化（一方可随时解约/调价/改约，另一方无对等权利）
- 成本转嫁（违约金远超损失、预付款远超履约进度、无限保密/竞业义务）
- 维权通道受损（管辖在对方所在地、无客观验收机制、无不可抗力免责、自动续约无退出机制）

示例（标 vs 不标）：

- "违约金按合同总金额的 30% 计算，不足部分另行赔偿" → **标**（R01，民法典 585 违约金可调减）
- "双方应按合同约定履行各自义务" → 不标（无实质不利）
- "付款方式：验收合格后 30 日内一次性支付" → 不标（对等合理）
- "委托开发成果归甲方，甲方支付对价，乙方保留背景 IP" → 不标（有对价买断）

## 三、R01–R13 风险定义

| 风险编号 | 风险名称 | 判定标准（法理含义） | 典型情形 | 法律依据 |
|---|---|---|---|---|
| R01 | 违约金过高 | 违约金明显超过实际损失，法院可调减 | 日 1% 累计超 20%、上不封顶、日 5% | 民法典 585 |
| R02 | 无限责任 | 赔偿责任无上限 / 覆盖一切损失 | "全部损失""一切责任""任何损失""含预期利益/间接损失" | 民法典 584 |
| R03 | 单方解约权 | 一方可随时无理由解约且无补偿 | 甲方有权随时终止、无需补偿；委托/承揽任意解除未补偿 | 民法典 562/563/933/787 |
| R04 | 管辖不利 | 管辖法院/仲裁地明确偏向对方（我方=甲方） | 由乙方所在地/对方所在地法院管辖 | 民事诉讼法 35 |
| R05 | 保密期不合理 | 保密义务永久/无限期，无合理边界 | "永久保密""无限期" | 民法典 501 |
| R06 | IP 权益失衡 | 无对价 / 明显不对称的成果利益剥夺（非"成果归甲方就标"） | 投入对等但甲方独占全部收益且乙方无补偿；乙方核心技术被无偿转走 | 民法典 859、860-864 |
| R07 | 付款义务失衡 | 付款义务与服务贡献明显脱钩 | 预付 80%、验收后拒不支付尾款 | 民法典 525/526、965 |
| R08 | 验收机制缺失 | 缺乏足以客观判断交付是否合格的验收机制 | 无验收节点/程序/后果；仅"验收合格后付款"无判断依据 | 民法典 621-623、845 |
| R09 | 不可抗力缺失 | 交付型商业合同无不可抗力条款，免责无据 | 未约定不可抗力处理（仅交付型合同标） | 民法典 180/590 |
| R10 | 竞业限制过宽 | 竞业范围/地域/期限超出合理限度 | 全国范围、所有行业、5 年+全行业禁入 | 劳动合同法 23/24 |
| R11 | 自动续约陷阱 | 期满自动续，无书面退出机制 | "期满未提出异议自动续期一年" | 民法典 734（类推） |
| R12 | 数据隐私不当 | 数据/个人信息共享、提供、转让无授权边界 | 客户数据可共享给第三方、研发体系内共享无脱敏 | 个人信息保护法 13/23、民法典 1035 |
| R13 | 名实不符 | 名义类型与实质法律关系不一致 | 名为服务外包实为劳务派遣 | 劳动合同法 66、民法典 146 |

## 四、特殊边界规则

> 以下边界规则用于消解「成果归甲方算不算风险」「异地算不算偏向」等主观争议，是标注可复现的关键。

### R04 管辖偏向
- 统一视角「我方=甲方」：管辖在乙方（对方）所在地 → 标；甲方/委托方/披露方所在地 → 不标。
- **"异地"不等于"偏向对方"**：必须能识别出约定的法院管辖地/仲裁地具有明确的对方地域偏向。
- 不能仅根据仲裁机构所在地推定；「争议解决条款冲突（同时约定法院+仲裁）」不构成 R04，属条款效力不确定提示。

### R06 IP 买断 vs 权益失衡
- **委托开发**：甲方支付明确对价 + 成果归甲方 + 乙方保留背景 IP → **不标**（标准买断结构，民法典 859 任意性规则允许约定）。
- **合作开发**：双方投入对等但甲方独占全部收益、乙方仅学术使用且无商业权利 → **标**（无对价收益独占）。
- **承揽**：承揽人利用定作人技术资料完成的改进成果、未付费开发成果 IP 均无偿归定作人 → **标**（智力成果无偿剥夺）。
- 「IP 归甲方所有」本身不等于所有相关权利都不存在；只有当乙方保留的复制/使用/许可/商业化等权利达到**实质削弱甲方的排他控制或商业化权益**的程度，才突破「买断不标」规则。

### R08 验收机制缺失
- 有完整验收机制（阶段验收 + 最终验收 + 宽限期 + 验收失败终止权/扣款）但缺技术指标 → **不标**（属「验收标准不完整」提示）。
- 只有「验收合格后付款」一句话，无验收程序/标准/后果 → **标**（缺乏客观验收判断机制）。
- 有「验收/点验/检查」字样 ≠ 有验收机制；外部国家标准不当然补足，除非合同明确援引并纳入；「质量争议时第三方鉴定」属争议处理机制，不能倒推为日常交付验收机制。

### R09 不可抗力（按合同类型）
- 仅**交付型商业合同**（买卖/承揽/建设/技术）通常必备 → 缺失标。
- **非交付型**（租赁/中介/委托/框架/物业）+ 劳动合同 + 保密协议 → **不标**。

### R10 商业竞业
- **劳动竞业**（劳动合同法 23/24）：超 2 年、超原经营范围/地域 → 标。
- **商业竞业**（非劳动关系）：期限 ≥5 年 **且** 范围全国/主营业务全禁 → 标；3 年同类项目排他 → 不标。

### R11 自动续约（强弱区分）
- 有退出通道（如期满前书面通知即可不续）→ 弱，通常不标；无上限自动续（如「顺延至交易结束」）→ 强，标。

### R13 名实不符
- 只标「名义 vs 实质」背离的（正文同时有名义信号与实质信号，且实质信号不处否定语境）。纯劳务派遣、劳动合同期限等**不标 R13**。
- R13 定位 = 规则信号示警、**单列报告、不进严格 F1**。

## 五、公告版 / 披露版处理原则（三条上位规则）

> 以下规则优先级高于各风险类型的判定，所有「公告 vs 披露版」冲突按此处理。

### 规则 A：风险存在性看披露版正文
风险有没有，看披露版合同文本实际写了什么。**公告仅用于校验，不用于无依据地补足披露版缺失内容。** 只有当披露版明确援引并纳入外部标准（如「按《技术规格书》第 X 条执行，该文件为本合同附件」）时，才可认为正文具备该机制。适用：R08（验收机制）、R09（不可抗力）、R04（争议解决）等所有「缺失型」风险。

### 规则 B：数值型风险严格按阈值
数值型风险（如违约金比例）严格按本规范明确约定的阈值判断，**不得以「年化后很高」「累计后超线」等方式变相扩大阈值**。例如 R01 阈值日 **5‰**；3‰/日即使年化 109.5% 也不触发 R01（可进 business_risks 提示，不进严格 F1 分母）。

### 规则 C：披露版与公告冲突分别记录
披露版与公告存在实质性冲突时，分别记录「披露版风险」和「公告—披露版不一致」，**不以公告内容直接覆盖披露版风险**。

## 六、不同合同类型的标注范围

> 缺失型风险（R08/R09）的基准按合同类型定，不一刀切。

| 合同类型 | 必查风险点 |
|---|---|
| 买卖/采购 | 违约金、质量验收、付款条件、无限责任、管辖、不可抗力 |
| 租赁 | 自动续约、违约金、维修责任、押金退还、管辖（R09 不标） |
| 建设/施工 | 工期违约金、付款节点、无限责任、验收、质保金、不可抗力 |
| 技术开发/服务 | IP 归属、保密期、数据隐私、验收机制、无限责任、不可抗力 |
| 物业/服务 | 服务标准、违约责任、自动续约、费用调整（R09 不标） |
| 委托/中介 | 报酬与付款、无限责任、单方解约、保密、自动续约（R09 不标） |
| 劳动合同 | 竞业过宽、服务期违约金、派遣三性（R13 例外）、保密期（R09 不标） |
| 保密协议 | 保密期限不合理、竞业过宽、无限责任（R08/R09 不适用） |
| 无名/混合 | 按实质条款逐项过上述所有项（R09 视是否交付型定） |

## 七、Gold 标注格式

每条风险标注 = `{risk_type: "R0X", desc: "一句话说明：条款要点 + 为什么是风险"}`

- 每份合同**全量标注**（不限于 1-2 条）；
- 同一条款同时触发多类风险的，**分别标注**；
- `desc` 必须含**条款要点**（可定位）——这是 span 级可复核的基础；
- 不进严格 F1 的提示项（如「验收标准不完整」「尾随期偏长」）→ 进 `business_risks` 字段，不进 `risks`。

## 八、标注质量控制

1. **双人背对背独立标注**：每批抽 10 份（覆盖 6+ 类型）双人独立标注，只依本规范与合同正文，互不参考、不参考引擎/LLM 输出。
2. **一致性指标**：Cohen's Kappa（主指标，排除偶然一致）或双人互当金标准算 F1（取均值）；目标 Kappa ≥ 0.6 或 F1 ≥ 0.7。
3. **「待议」兜底**：拿不准的案例先标「待议」，讨论后定标，不各自硬判。
4. **定标回写**：不一致的逐条经组员人工复核定标，定标结果写回 Gold；跨批回溯同类条款，保证一致。

> Gold 的形成 = 双人背对背标注 → 一致性校验 → 争议案例人工复核定标 → 写回 Gold。定标以组员人工复核为准，**不把任何模型/引擎输出作为 Gold 的判定来源**。
