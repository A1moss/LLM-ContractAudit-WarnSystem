## 二、各技术点 → 本项目实现映射

| 技术点 | 本项目落地位置 |
|---|---|
| Transformer / LLM | `backend/ai/llm_client.py`（DeepSeek `deepseek-chat`） |
| RAG 检索增强 | `backend/ai/rag/`（ChromaDB 向量库 + BM25），分类器 `backend/ai/classifier/rag_classifier.py`，建议层 `backend/ai/auditor/recommendation_engine.py` |
| 句向量 / 语义检索 | `backend/ai/rag/vector_store.py`（`shibing624/text2vec-base-chinese` + `sentence-transformers`） |
| 关键词检索 | `backend/ai/rag/bm25.py` |
| 信息抽取（要素/条款） | `backend/ai/extractor/extractor.py`（四要素）、`backend/ai/auditor/evidence_extractor.py`（风险事实证据） |
| 法律域理解 | 法条库 `backend/ai/knowledge/laws.json`、标准条款库 `standard_clauses.json`、风险法条映射 `RULE_LAWS` |
| P/R/F1 评测 | `backend/evaluate/evaluate_rag.py` / `evaluate_elements.py` / `evaluate_evidence.py` |

## 三、说明

- 以上文献均为本项目在**方法层面**的公开技术依据；项目本身没有复现或直接调用上述论文的模型权重（LLM 走 DeepSeek API，嵌入走 `text2vec-base-chinese`）。
- 未收录任何未经核实的论文、作者或 DOI；如需补充中文法律 NLP 数据集（如 CAIL）等，需先经 web 检索核实后再入库。
