## 四、gold 标注口径

- **标注方式**：组员**背对背独立标注**——标注者只依据标注口径清单与合同正文判断，互不参考、互不影响，保证标注客观中立。
- **裁定流程**：标注分歧点引入 **AI 辅助法理审核**，结合法条与司法解释裁定后定标，写回 gold。
- **权威标准**：`docs/风险标注口径.md`（v1.2.4），含三条上位规则（规则 A/B/C）与 R01–R13 逐类法理定义。

## 五、三大硬指标（实测）

| 硬指标 | 门槛 | 实测 |
|---|---|---|
| 法理分类准确率 | ≥85% | **97.62%**（82/84，技术 1 份 + 劳动 1 份误判） |
| 要素抽取 F1 | ≥80% | **90.7%**（宏平均：双方 95.2 / 金额 84.6 / 期限 85.9 / 争议 96.3） |
| 风险识别精准率 | ≥75% | **76.6%**（TP 121 / FP 37 / FN 30，F1 78.3%） |
| 风险识别召回率 | ≥75% | **80.1%** |

风险引擎经过多轮架构迭代，最终收敛为「**LLM 只抽事实 + Python 确定性规则裁决**」：LLM 不做风险判断，只抽取条款客观事实证据，由代码按 v1.2.4 口径的硬阈值裁决 R01–R12，保证可复现、同模板一致。
