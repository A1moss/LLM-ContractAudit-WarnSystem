## 已删除/归档的历史模块（不在当前架构）

| 名称 | 状态 | 说明 |
|---|---|---|
| Corex 多 Agent | 已删除 | 原「多 Agent 交叉验证」已由「证据-裁决 + 多来源置信度融合」取代 |
| `reporter/` | 已删除 | 报告组装已内联到 `api/contracts.py` |
| Dify | 已删除 | `dify_client.py` 与 Dify 样例已移除 |
| KNN classifier | 已删除 | 分类统一走 RAG 少样本 + 零样本兜底 |
| `audit_with_llm` | 归档（`llm_auditor.py` 内函数） | 旧「precise = 规则 + LLM 直审」口径，由 v6.4「证据抽取 + 确定性裁决」取代，仅评测 `evaluate_risks.py` 引用 |
| 报告导出（HTML/PDF/Markdown） | 无此功能 | 报告为 HTML 在线预览 |
| heatmap 端点 | 无此端点 | 风险等级分布随 `audit-report` 返回 |

> 这些模块只作为「历史演进」记录，**不是**当前生产架构的一部分。
